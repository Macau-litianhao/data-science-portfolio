# data-science-portfolio

Source of my data science portfolio site, published with GitHub Pages.

**Live site:** https://macau-litianhao.github.io/data-science-portfolio/

## How this works

- `index.md` — the homepage. GitHub Pages renders it as the site's entry page.
- `images/` — figures referenced by `index.md` using relative paths.

## Linked project

[data-science-project](https://github.com/Macau-litianhao/data-science-project) — an analysis
of stroke mortality in China, 2000–2021: why total stroke deaths rose while the
age-standardised death rate fell.

## Deployment

Settings → Pages → Deploy from a branch → `main` / `(root)`. Any commit to `main` is
republished automatically within about a minute.
